Installing Founder Skills

Opening Claude…

Claude didn’t open. You can:

Try again

Or install it by hand, in the Claude desktop app:

  1. Click Customize in the sidebar, then Plugins.
  2. Click Add ⌄ → Add marketplace.
  3. Enter lool-ventures/founder-skills and leave Sync automatically on.
  4. Click Sync.
  5. In the Directory, click + on the Founder skills card. Syncing alone does not install it.
